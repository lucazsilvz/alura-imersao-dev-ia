## 🧮 Detalhes do Desafio 01: Calculadora CLI em Python

Aplicação de terminal desenvolvida com o apoio do Google AI Studio para explorar a sintaxe da linguagem Python e a anatomia de um software.

### 🧠 Principais Aprendizados:
- **Engenharia de Prompt:** Uso do Google AI Studio para guiar a IA na geração de código limpo, didático e modular.
- **Funções (`def`):** Modularização de cada operação aritmética básica (+, -, *, /).
- **Tipagem e Conversão (`float`):** Conversão de dados capturados via terminal (texto) em números decimais para cálculos.
- **Estruturas Condicionais (`if / elif / else`):** Lógica de tomada de decisão para direcionar a operação escolhida pelo usuário.
- **Programação Defensiva:** Prevenção contra divisões por zero (`ZeroDivisionError`).

## ⚡ Detalhes do Desafio 02: Evoluindo sua Aplicação com Google Antigravity

Evolução do código da calculadora explorando o ciclo completo de Engenharia de Software no Google Antigravity: compreensão de código legado, adição de novas funcionalidades e validação contínua através de testes automatizados.

### 🧠 Principais Aprendizados:
- **Exploração e Análise de Código:** Leitura e compreensão da estrutura de um projeto existente com assistência do Antigravity.
- **Evolução de Funcionalidades:** Implementação da operação de porcentagem (`%`) mantendo a integridade das funções anteriores.
- **Testes Unitários Automatizados (`unittest`):** Criação de testes para verificar assertivamente que nenhuma operação existente quebrou (prevenção de regressão).
- **Refatoração & Usabilidade:** Implementação de laço contínuo com menu interativo e tratamento de exceções robusto.

## 📝 Detalhes do Desafio 03: Criando uma Lista de Tarefas com Google Antigravity

Desenvolvimento do zero de uma aplicação de gerenciamento de tarefas (*To-Do List*) com interface gráfica interativa, separação de responsabilidades (HTML, CSS e JavaScript) e suíte de testes unitários.

### 🧠 Principais Aprendizados:
- **Arquitetura em Camadas:** Divisão limpa entre estrutura semântica (`index.html`), estilo visual (`style.css`), lógica de negócio e manipulação do DOM (`app.js`).
- **Operações Fundamentais:** Adicionar, marcar como concluída e remover tarefas.
- **Diferenciação Visual:** Estilização dedicada para tarefas concluídas (texto tachado, cor atenuada, badge verde e transições suaves).
- **Persistência de Dados:** Armazenamento local no navegador via `LocalStorage`.
- **Testes Unitários:** Validação automatizada de regras de negócio com o test runner do Node.js.
