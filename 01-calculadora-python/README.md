# 🧮 Desafio 01: Construindo sua Primeira Aplicação com Google AI Studio

Primeiro projeto desenvolvido durante a **Imersão Dev: Engenharia de Software na Era da IA** (Alura & Google).

O objetivo deste desafio foi explorar a sintaxe fundamental da linguagem Python com o auxílio do **Google AI Studio**, compreendendo o fluxo de entrada de dados, conversão de tipos, estruturas condicionais e funções modulares.

---

## 🛠️ Tecnologias & Conceitos

- **Linguagem:** Python 3
- **Google AI Studio / Gemini:** Apoio na ideação e geração de código didático
- **Modularidade:** Funções dedicadas para cada operação matemática (`somar`, `subtrair`, `multiplicar`, `dividir`)
- **Programação Defensiva:** Tratamento para evitar divisão por zero (`ZeroDivisionError`)
- **Controle de Fluxo:** Estruturas de decisão `if / elif / else`

---

## 🚀 Como Executar

Execute no terminal dentro desta pasta:

```bash
python calculadora.py
```
