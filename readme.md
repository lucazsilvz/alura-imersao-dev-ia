## 🧮 Detalhes do Desafio 01: Calculadora CLI em Python

Aplicação de terminal desenvolvida com apoio do Google AI Studio para explorar a sintaxe e a lógica fundamental do Python.

### Principais Aprendizados:
- **Funções (`def`)**: Modularização do código para cada operação matemática.
- **Tipagem e Conversão (`float`)**: Tratamento de dados vindos do terminal como texto para valores numéricos.
- **Controle de Fluxo (`if / elif / else`)**: Estrutura lógica de tomada de decisão para execução das operações.
- **Tratamento Defensivo**: Proteção contra divisão por zero (`ZeroDivisionError`).
